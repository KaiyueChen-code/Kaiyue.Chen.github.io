# Kaiyue Chen — Academic Homepage

Personal academic homepage for Kaiyue Chen, an undergraduate in Mechatronics
and Robotic Systems at Xi'an Jiaotong-Liverpool University.

This is a build-free static site. The page lives in `index.html`, with styles
in `stylesheet.css` and local assets under `assets/` and `images/`.

For a local preview:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

Content was migrated from the previous homepage in `Kaiyuechen.github.io`.
The selected publication, 3WD-VLA, is accepted at EAI CollaborateCom 2026.
The CV link is omitted because
the previous site's configured `files/CV-Kaiyue-Chen.pdf` was not present.

Canonical and social-sharing URLs use the GitHub Pages project path for this
repository: `https://kaiyuechen-code.github.io/Kaiyue.Chen.github.io/`.
Update these URLs in `index.html` if the repository is renamed or a custom
domain is configured.

The visual template is adapted from Jiayi Zhang's academic homepage.
The original MIT license is retained in `LICENSE`.

The university logo in `images/xjtlu-logo.png` comes from XJTLU's official
[University Identity page](https://www.xjtlu.edu.cn/en/about/overview/xjtlu-identity).

version made with the built-in imagegen tool. Prompt: remove the white
